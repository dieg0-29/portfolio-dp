## The project

TrikaWeb is a collaborative platform built at UNICODE to browse and share university resources: past exams, solutions, course information and professor ratings. I worked on it from February to September 2026.

## My contribution

- Extended the database to support the evaluation systems and subsystems of each course.
- Standardized file uploads with dropdown selectors, reducing manual errors.
- Redesigned the admin panel with a dynamic sidebar menu.
- Set up restrictive authentication that only accepts institutional email addresses at sign-in.

## Stack

Astro and React with Tailwind CSS on the frontend, Astro API routes on the backend, and Supabase (PostgreSQL, Auth and Storage) for data, authentication and files. End-to-end tests run on Playwright.
